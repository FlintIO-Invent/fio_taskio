CSV format

Required columns:

  • name
  • unit_price

Optional columns:

  • description
  • tax_rate
  • category
  • is_active
  • external_code
  • is_bookable_online
  • default_duration_minutes
  • booking_buffer_minutes
  • public_description
  • requires_manual_confirmation

Prices are stored as decimals. Use 1234.56, or {{ price_input_example }} for this workspace format.

If tax_rate is blank, Motionmate uses the current workspace default {{ business.tax_label|default:"Tax" }} rate of {{ business.tax_rate|floatformat:2 }}%.

If booking columns are omitted, existing booking settings on matched services are left unchanged.
