# Subscription implementation

The 16 approved paths are implemented: Services-only dispatch, eight scoped
templates, Manrope CSS, real Django/browser tests and owned validation adapters.
Current status and the existing effective-access message come first; billing
actions retain recovery, portal and resumable-checkout priority and original
beta/availability guards. Usage and plan prices/allowances remain server values.
Plan comparison has nearby pilot guidance, bound errors and the complete
quota/module-loss confirmation with its original second-submit key.

Original Logistics content bytes, routes, HTTP methods, CSRF fields, hidden plan
IDs and workspace mutation guards remain intact. No handler, model, integration,
financial formula, migration, dependency, shared shell or peer module changed.
The existing no-subscription read-only UI and free-test POST policy are preserved.

The environment restart and exact source reconstruction are documented in
[source recovery](source-recovery.json). Fresh fixtures replace no old database;
all old temporary resources were absent. Migration-generated plan audit times
are excluded only from cross-side canonical parity, with complete raw facts
retained per side for later preservation checks. Existing source/approval/global
baselines are not rewritten. Prior Gate C source candidates stay frozen; fresh
resource identities supplement their historical runtime proofs.

The ten legacy portal service tests retain their assertions in a new
quota-valid fixture in the approved test file. Nine bodies are inherited; the
inactive-workspace case creates membership before making its fixture inactive. Original setup adds staff without
a subscription and failed identically on BEFORE and AFTER. The replacement
uses a temporary local subscription while constructing its own membership
fixture, then removes only that setup row before the inherited cases create
their original provider states. Runtime guards and original tests are unchanged;
no production policy is bypassed or patched. Raw failure evidence is retained.
